# Турник и Ко

Личное приложение для домашних тренировок. Открывается на телефоне через GitHub Pages, ничего собирать не нужно.

- `index.html` — приложение
- `data.json` — план, упражнения и еда (редактирует тренер)
- `sw.js`, `manifest.webmanifest` — работа без интернета и установка на главный экран
